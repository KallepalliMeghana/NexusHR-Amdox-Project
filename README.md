# NexusHR – AI-Enabled Human Resource Management System 

## Overview

NexusHR is a full-stack Human Resource Management System developed using Java Spring Boot, Thymeleaf, JPA, and H2 Database. The application streamlines HR operations including employee management, attendance tracking, leave management, payroll processing, and workforce analytics.

## Features

* Employee Management
* Attendance Tracking
* Leave Management
* Payroll Processing
* AI-Based Workforce Risk Analysis
* Dashboard Reporting
* Responsive User Interface
